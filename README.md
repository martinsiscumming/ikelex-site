GLOBAL ANIMATION PHILOSOPHY

============================================================

THIS WEBSITE MUST HAVE A LOT OF ANIMATION.

But the animation must feel cinematic and premium.

The experience should feel alive while scrolling.

As the user scrolls:

- elements should pop into view

- images should reveal themselves

- cards should rise into place

- text should reveal progressively

- backgrounds should move subtly

- large elements should parallax

- sections should transition into one another

- cards can stack and unstack

- images can drift

- timelines should progress

- numbers can count up

- decorative elements can move

- buttons should react to the cursor

- navigation should transform while scrolling

Use:

opacity

translate

scale

blur

clip-path

mask reveals

spring physics

stagger

parallax

sticky sections

scroll progress

cursor interaction

IMPORTANT:

Do not animate every element independently.

Create a clear motion hierarchy.
